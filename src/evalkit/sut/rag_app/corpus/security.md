# Security and data protection

## Encryption
All notes are encrypted at rest with AES-256 and in transit with TLS 1.3. Team plan customers can enable end-to-end encryption per notebook; when it is enabled, Nimbus Notes staff cannot read the notebook and cannot recover it if the passphrase is lost.

## Data residency
Customer data is stored in the EU (Frankfurt) region by default. Team plan customers can choose the US (Virginia) region when creating the workspace. Moving an existing workspace between regions is not supported.

## Two-factor authentication
Two-factor authentication supports authenticator apps and hardware security keys. SMS codes are not supported. Team administrators can make two-factor authentication mandatory for every member.
